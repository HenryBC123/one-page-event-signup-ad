# 踩坑紀錄（2026-10～11 小室房屋 11/17 分享會實戰）

## 海報（HTML → PNG）
- 用 `scripts/render.sh`。圖片、字體、QR 一律放在 html 同資料夾、用**相對路徑**——絕對路徑含中文時 Chrome 讀不到（PDF 變 8KB 空白就是這個）。
- 講師照淡出用多層 `-webkit-mask-image` 漸層＋`-webkit-mask-composite: source-in`；照片邊緣有雜物（鞋子、椅腳）就多加一層從那一側淡出，不要放大裁切（會疊到講師名字）。
- 主題列表和底部資訊欄會互擋：改完一定看整張圖，確認第 5、6 項沒被蓋住。
- zsh 陣列從 1 開始：`names=(a b c)` 時第 i 個是 `${names[$i]}`，不是 `$i-1`。

## Google 表單
- **登入、授權「允許」都要使用者本人做**。授權視窗出現時停下來，請使用者點「審查權限 → 選帳號 →（未驗證就點進階 → 前往）→ 允許」。
- 用 `FormApp.create()` 建新表單。不要先在介面開空白表單再 `openById`——會「找不到指定 ID 的項目」。
- Apps Script 編輯器可用瀏覽器 JS：`monaco.editor.getModels()[0].setValue(程式碼)` 貼上 → Cmd+S → 按「執行所選函式」。執行記錄用 `[aria-label*="記錄"]` 讀。
- 編輯器裡只放要跑的那個函式，避免誤跑 `setupForm` 又建出第二份表單。
- 加了 `UrlFetchApp`（抓海報圖）會需要再授權一次。
- 圖片項目放不到表單標題上面。固定順序：短說明 → 海報圖 → 「活動介紹」段落 → 題目。
- 表單裡的海報圖是複製進去的；換海報要重新部署圖片後再跑一次 `updateDescription`。

## 報名網頁 → 試算表
- 網頁用 `fetch(formResponse, {method:"POST", mode:"no-cors"})` 送進 Google 表單，資料自動進同一份試算表，不用另寫後端。
- entry ID 用 `scripts/form_entries.py <viewform 網址>` 取。**選項文字必須與表單一字不差**（含全形破折號 –、空白），不然那題資料會進不了試算表。
- 部署後驗證：實際送一筆「測試（可刪）」→ 開試算表確認有進 → 請使用者自己刪那一列。
- 瀏覽器會吃到舊版快取：檢查時網址加 `?v=數字`。
- 手機尺寸（375 寬）檢查：長按鈕要 `white-space:nowrap` 並縮字；長品牌名手動 `<br>` 斷行，不要讓它斷在英文單字中間。

## 短影音簡報
- 使用者要「字可以改」→ 用 `scripts/build_pptx.py` 產生文字框版，不要用整張圖片塞進投影片。
- 字體用 PingFang TC（Mac 內建）。Windows 開會被換字，要提醒。
- 驗證：用 Keynote AppleScript 輸出每頁 PNG 再看（`export d to POSIX file … as slide images`）。
- 單行大標題的副標要往上移（腳本已自動處理），兩行大標題行距 0.95。
- 重點每條 ≤11 個字，超過會擠出卡片。
- 改簡報前先看檔案修改時間：使用者可能已在 PowerPoint／Keynote 裡手改，重新產生會蓋掉。
- 亮色版重點色用 #9a7449（深棕金）；原本的米色 #e3cda8 在白底上看不清楚。

## 內容
- 押金上限、轉租、違約金、欠租終止、修繕扣租、租金補貼與稅務這類內容，一律提醒「發布或錄影前請再確認最新規定」；補貼規則每期都可能變。
- 篩選房客的內容要提醒反歧視：不能以性別、年齡、身障、婚姻等理由拒租。
