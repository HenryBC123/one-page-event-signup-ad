# event-kit｜活動招生套組

Claude Code skill：辦講座、分享會時，一次做出整套招生素材。

- 直式海報 1080×1920（講師照淡出、6 主題、報名 QR code）
- Google 報名表單＋名單試算表（Apps Script 一鍵建立）
- 一頁式報名網頁（Vercel），送出直接進同一份試算表
- 短影音背景簡報：每主題標題頁＋6 重點頁，字可改的 PPT＋PDF

## 安裝

把整個資料夾放到 `~/.claude/skills/event-kit/`，在 Claude Code 說「我要辦一場講座」就會啟動。

範例內容：小室房屋「房東出租全攻略」11/17 屋主分享會。字體 Noto Sans TC 為 OFL 授權。
